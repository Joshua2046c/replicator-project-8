# 圆饼保护套

收纳 Ø28.9 × 5.1 mm 圆饼，两面均有 Ø25 mm 同轴圆洞，保留皮套式挂绳耳与周边立体仿缝线。

## 平台决定
纯机械产品，无电路、开发板或供电。

## 结构与尺寸
- 两个制造件：下纹理面与中间套圈合成的一体下壳，以及独立的上纹理面盖。下壳底面与侧壁为连续实体，没有分件缝。
- 按图中竖向标线，将中段沿高度方向加厚 0.125 mm，中段与内腔净高为 5.405 mm；圆饼厚 5.1 mm，轴向余量为 0.305 mm。内圈按半径向内缩 0.06 mm，内腔直径 29.18 mm，直径余量 0.28 mm。
- 主体外径 39.6 mm，含挂绳耳总高约 47.8 mm。下壳底面基体厚 1.3 mm，上面盖基体厚 1.3 mm，两面针脚相对外侧基准面各凸起 0.4 mm（原高度的两倍），浅凸环与滚边保持 0.2 mm，合拢总厚 8.805 mm。
- 上盖接面位于 Z=6.705 mm，外缘直角、接面平整；无卡扣、榫槽或定位销。上盖同步上移 0.125 mm，保证接面贴合。
- 挂绳槽为 10.5 × 3 mm 圆角孔、圆角 1.2 mm，槽中心 Y=24 mm，两侧 X=±5.25 mm，与下方颈部内侧装饰线同宽对齐；耳宽 16 mm、顶部 Y=28 mm。下壳耳部下表面保持 Z=4 mm，下壳耳部厚 2.705 mm，加上盖后厚 4.005 mm。
- 挂绳颈部左右两处内侧装饰线凹圆角均为 R4 mm；外侧凹圆角为 R3 mm。下壳挂绳耳背面外缘与另一面采用相同圆角，沿用 R0.45 mm；背面沿耳部 U 形外圈补齐仿缝线，针脚与另一面同为 1.9 × 0.6 mm、凸高 0.4 mm、名义节距 2.7 mm；标记的耳根针脚与上方同为 1.9 × 0.6 mm、凸高 0.4 mm，下半部分沿圆形主体边界裁掉。
- 默认棕色 TPU 95A，FDM 成型，立体仿缝线可手工涂米白色。纹理为一体几何装饰，不是真实线缝。
- 默认沿唯一一道上盖接面薄涂适配 TPU 的柔性胶永久固定；日常防刮与轻微磕碰，不宣称防水、跌落认证或长期钱币保存材料等级。

## 参考与验收
外观参考原始棕色皮套图。结构依据用户标图：下纹理面与中间套圈合为一件；侧边竖向绿色标线所示中段沿轴向加厚 0.125 mm。

验收：颈部左右内侧凹圆角均为 R4 mm；内腔直径 29.18 mm，两面所有针脚凸起 0.4 mm，挂绳槽两侧与下方内装饰线对齐；两个零件各为有效单一实体；下壳底部无分件缝；中段净高 5.405 mm，仍容纳 Ø28.9 × 5.1 mm 圆饼；两面孔 Ø25 mm；上盖接面贴合且无实体干涉；挂绳槽与仿缝线保留，耳部背面具有与另一面相同的外缘圆角与 U 形仿缝线。
